# CalcTraining

(謎の存在)カリキュレイダーとして、謎の敵をやっつけよう

## 概要
数学が得意になるための重要な要素とはなにか、と考えてみると、基礎的な計算能力が一つ挙げられる。
計算ミスを減らし、計算が素早くなることで、計算を苦に感じなくなるのではないだろうか？
- 「これくらいなら暗算でできるわ」
- 「ああ、計算すればいいのね」
こういったマインドが初期の数学嫌いを減らせるはずだ。

そのために必要なのは、四則演算の習熟。
このために、ゲームを作成し、楽しみながらひたすらに計算を進めるようなアプリケーションの作成を考えた。

## 技術選定
学校現場で使用する際、webアプリは（管理者によって制限されなければ）使いやすい。

一方で、リリースにはサーバーを用意するコストがかかる。

スタンドアロンのアプリケーションならば、サーバーのコストはかからないが、導入には自治体の審査が入る。
どうしたものか、、、。

結果としてReactで全部作って、Cloudflare Pagesに投げる形にします。

## 仕様
5分間の制限時間で難易度別に設定される目標問題数を正答することをクリア条件とする。
### 難易度
- 初級：30問(10s/問)
- 中級：50問(6s/問)
- 上級：100問(3s/問)
### ステージ
- 加算、減算、、、展開、因数分解、、などなど
### お助けキャラを用意
チャレンジチャンス(受諾すると難易度の高い問題を出題、成功で大ダメージ)の発生用
成功するとタイムアタックにプラスになる。必須ではない。
10問正答ごとに攻撃演出。インターバルも兼ねる。
この演出がかっこいいことが重要。
タイムボーナスをつけて、早いと難易度の問題数より少なくクリアできるようなダメージが出る。
チャレンジチャンスに成功すると10問正答と同じダメージが出る。
同じ日付の中では1回しかできない。2回目以降はカカシをひたすら殴るだけ。3ミスした時に、友達がやっているのを指を咥えて見なきゃいけないっていう感じで、計算ミスを抑制。
### 終了時演出
- 0ミス
クリア:完勝。主人公からも感謝される
失敗:敵がビビりながら逃げてく
- 1ミス
クリア:辛勝。主人公は感謝するが、、、
失敗:敵が割と余裕そうに帰っていく。
- 2ミス
クリア:ほぼ痛み分け。もっと強くならないと、的な
失敗:ほぼ負け。今日はこれくらいで勘弁してやろう的なことを言われる。
